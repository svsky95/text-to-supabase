# 部署指南

## 本地运行

```bash
cd text-to-supabase
npm install
npm run dev
```

访问 http://localhost:3000

---

## Supabase 数据库设置

### 1. 创建项目
1. 访问 https://supabase.com 创建账号
2. 点击 "New Project" 新建项目
3. 设置密码（妥善保存）

### 2. 获取连接信息
在项目设置中获取：
- `Project URL` → 作为 `NEXT_PUBLIC_SUPABASE_URL`
- `anon public` key → 作为 `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### 3. 创建数据表
在 Supabase SQL Editor 执行：

```sql
CREATE TABLE text_entries (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 启用车轮锁（允许插入）
ALTER TABLE text_entries ENABLE ROW LEVEL SECURITY;

-- 创建公开插入策略
CREATE POLICY "允许公开插入" ON text_entries
  FOR INSERT TO anon
  WITH CHECK (true);
```

## Vercel 部署

### 1. 推送代码到 GitHub
```bash
cd text-to-supabase
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/你的用户名/text-to-supabase.git
git push -u origin main
```

### 2. Vercel 导入
1. 访问 https://vercel.com
2. Import GitHub 仓库
3. Framework: Next.js（自动检测）
4. 添加环境变量：
   - `NEXT_PUBLIC_SUPABASE_URL` = 你的 Supabase Project URL
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = 你的 anon key

### 3. 部署
点击 Deploy，Vercel 会自动构建并发布。

## Cloudflare（可选）

用于加速和域名管理：

1. 在 Cloudflare 添加域名
2. DNS 设置指向 Vercel：
   - 类型: A
   - 名称: @
   - 内容: 76.76.21.21
3. 启用 CDN 加速

或者使用 Cloudflare Pages 替代 Vercel：

1. 连接 GitHub 仓库到 Cloudflare Pages
2. 构建命令: `npm run build`
3. 输出目录: `.next`
4. 环境变量添加同样的两个 key

---

## 环境变量说明

| 变量名 | 来源 |
|--------|------|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 项目设置 → General |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase 项目设置 → API |
